## Screen

### What is the 'Built up areas' consideration?

[Built-up areas (BUAs)](https://www.ons.gov.uk/peoplepopulationandcommunity/housing/articles/townsandcitiescharacteristicsofbuiltupareasenglandandwales/census2021) are a geography based on the physical built environment, using Ordnance Survey topographic data to recognise developed land, such as cities, towns, and villages. This allows economic and social statistics to be investigated based on actual settlements where most people live.

BUAs are classified by population size as minor, small, medium, large or major, and characteristics are explored using Census 2021 data.

### What are the planning needs for this data?

In order to support analysis into land use, statistical data such as built up areas can be used. Using this dataset, we are able to see what land is not built-up, and which can contribute towards understanding what land is available for development. While this is a useful statistical dataset, a more precise source will be required for site selection purposes.
